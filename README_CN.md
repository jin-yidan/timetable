# 时间表

一个简单的日程管理应用，支持网页版、PWA、macOS 桌面小组件和 iOS 应用，并通过 iCloud 同步数据。

[English](README.md)

## 下载

**macOS 应用：** [下载 Timetable.zip](../../releases/latest)

1. 下载并解压
2. 将 Timetable.app 拖到"应用程序"文件夹
3. 首次打开：系统设置 → 隐私与安全性 → 点击"仍要打开"

**iOS 应用：** 通过 Xcode 编译安装（见下方说明）

## 功能

- **时间线**：以列表或 24 小时时间块显示每日事件
- **周视图**：一览整周安排
- **待办**：按日期分组显示所有未完成任务
- **计划**：设置全年每月目标
- **重复事件**：支持每天、每周、每月重复
- **中国节假日**：自动显示法定节假日和二十四节气
- **日历同步**：导入 iCal 链接（如大学课表）
- **iCloud 同步**：通过 CloudKit 在 macOS 和 iOS 之间同步事件、目标和设置
- **离线使用**：首次加载后无需联网
- **隐私保护**：所有数据仅存储在你的设备上，通过个人 iCloud 同步

## 使用方法

### 添加事件
1. 点击"Add event"
2. 输入时间（开始时间，结束时间可选）
3. 输入标题
4. 可选：添加备注、设置重复、标记为重要
5. 点击"Add"

### 管理事件
- 点击圆圈标记完成
- 点击 ⋯ 编辑或删除

### 导航
- 箭头按钮切换上一天/下一天或上一周/下一周
- 点击日期跳转到指定日期
- 标签页：Timeline（时间线）、Week（周）、Upcoming（待办）、Planner（计划）

### 导入日历
1. 点击齿轮图标
2. 粘贴 iCal 链接
3. 点击 Save

### iCloud 同步
运行原生 macOS 或 iOS 应用时，同步自动进行。事件、目标、重复任务状态和设置会在所有登录同一 iCloud 账号的设备之间同步。

## 从源码编译

1. 用 Xcode 打开 `xcode/Timetable.xcodeproj`
2. 选择目标：
   - **Timetable** — macOS 应用
   - **Timetable iOS** — iOS 应用
3. 选择你的签名团队
4. 编译运行（Cmd+R）

如需 iCloud 同步，请在"签名与功能"中启用 iCloud（CloudKit）功能，并选择容器 `iCloud.com.jinyidan.Timetable`。

## 网页版

用浏览器打开 `index.html`，或访问 https://jin-yidan.github.io/timetable/

安装为 PWA：
- iOS：分享 → 添加到主屏幕
- Android：菜单 → 安装应用
- 桌面浏览器：点击地址栏的安装图标

## 数据存储

所有数据都存储在本地浏览器或应用中。原生应用可通过 iCloud CloudKit 同步（使用你的个人 iCloud，不经过任何第三方服务器）。
